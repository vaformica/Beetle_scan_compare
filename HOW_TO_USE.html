Beetle Scan Compare

A practical guide to matching and rapidly reviewing two folders of beetle scan images.

Install Match folders Rapid review Jump around Export

1. Install on another Mac

  1. Open Beetle-Scan-Compare-0.1.0-Apple-Silicon.dmg.
  2. Drag Beetle Scan Compare to the Applications folder.
  3. Open it from Applications. For the unsigned research build, the first launch may require Control-clicking the app and choosing Open.

The DMG includes Python and Pillow. No separate dependencies are needed. This build supports Apple Silicon Macs (M1, M2, M3, M4, or newer).

2. Select and match the folders

  1. Choose Folder 1 and Folder 2.
  2. Select Dorsal (-D), Ventral (-V), or Right (-R).
  3. Enable subfolders only if the images are nested inside other folders.
  4. Leave the minimum match at 82% initially, then click Match Images.
  5. Read the matched and unmatched counts before starting.

Ambiguous or weak filename matches are reported as unmatched; the program does not silently guess. Source images are never changed.

3. Rapid review

  1. Click Start Rapid Review.
  2. Press A to approve or R to reject. Each decision saves immediately and advances to the next pair.
  3. Use the arrow keys or Previous/Next buttons to move without deciding.

4. Revisit or jump to a pair

The right-hand Pair Navigator contains two tabs:

  • All Matched Pairs lists every pair, both filenames, match score, and current decision.
  • Rejected Pairs contains only current rejections.

Use the vertical or horizontal scrollbar, then double-click a row—or select it and click Show Selected Pair—to jump to that pair. Jumping does not change the saved decision. Press A or R if you want to replace it.

5. Save the review

Click Export CSV Lists and choose a permanent output folder. The app creates:

  • a timestamped review-decision CSV containing every matched pair; and
  • a timestamped unmatched-image CSV reporting files from both folders.

The in-progress review is also autosaved after every decision in the Mac temporary folder as beetle-scan-compare/current_review.csv.
